Plan: Compute a Reference \(w_{\mathrm{avg}}(t)\) by Forward Perturbation of a Shared-\(\sigma\) GMM Marginal Flow

Implementation specification for a coding agent. The target latent distribution is always modeled as an equally weighted Gaussian mixture model. Every component has the same isotropic standard deviation \(\sigma\). The goal is to estimate the average squared contribution of a local state perturbation at time \(t\) to the endpoint error.

Main idea. Construct the reference marginal velocity \(v(x,t)\) induced by the GMM target. At a query state \(x_t\), propagate both \(x_t\) and a small perturbation \(x_t+\varepsilon u\) through the same marginal ODE. Their endpoint separation estimates the action of the state-transition operator on direction \(u\). Average over random directions and marginal query states to obtain \(w_{\mathrm{avg}}(t)\).

0. Background: Flow Matching and purpose of this experiment

0.1 Flow Matching in one paragraph

Flow Matching trains a time-dependent velocity model \(v_\theta(x,t)\) that transports a simple source distribution, typically \(p_0=\mathcal N(0,I)\), into a target data distribution \(p_1\). For the standard independent linear conditional path,

\[ x_t=(1-t)x_0+t x_1, \qquad x_0\sim p_0,\quad x_1\sim p_1, \]

the conditional velocity is \(u=x_1-x_0\). The population-optimal Flow Matching predictor is the marginal velocity

\[ v(x,t)=\mathbb E[x_1-x_0\mid x_t=x]. \]

At generation time, samples are produced by integrating the marginal ODE

\[ \frac{dx_t}{dt}=v(x_t,t) \]

from the source side to the target side. The conditional straight line is therefore a device for defining the marginal path and the training target; it is generally not the trajectory followed by the marginal ODE.

0.2 Why Path-Weighted Flow Matching needs this experiment

A velocity-prediction error made at one timestep does not necessarily have the same effect on the final generated sample as an equally large error made at another timestep. Once a small state error exists, the remaining marginal dynamics can amplify, rotate, or suppress it. Path-Weighted Flow Matching therefore aims to assign a larger scalar training weight to timesteps whose local errors contribute more strongly to endpoint error.

The ideal local-to-endpoint sensitivity is represented by the state-transition operator \(\Phi(1,t)\). A natural scalar summary for isotropic local errors is

\[ w_{\mathrm{avg}}(t) = \mathbb E_{x_t\sim p_t} \left[ \frac{1}{d}\|\Phi(1,t)\|_F^2 \right]. \]

The purpose of this experiment is to estimate this quantity as a reference curve directly from the target latent distribution, without using a trained Flow Matching model and without replacing the full local dynamics by a scalar Jacobian approximation.

0.3 What this program should do

The program will:

  1. represent the target latent distribution by an equally weighted shared-\(\sigma\) GMM;
  2. evaluate the corresponding analytical reference marginal velocity \(v(x,t)\);
  3. sample query states \(x_t\sim p_t\);
  4. apply a small random perturbation at time \(t\);
  5. integrate the unperturbed and perturbed states forward through the same reference marginal ODE;
  6. measure their endpoint separation and average it over probes and query states;
  7. produce \(w_{\mathrm{avg}}(t)\), uncertainty estimates, and numerical-convergence plots.
Scope. This is an offline diagnostic/reference experiment. It does not train a neural velocity model. Its main use is to test how well simpler analytical timestep weights approximate the error amplification of a more faithful target-distribution model.

1. Target quantity

Let the reference marginal ODE be

\[ \frac{dx_s}{ds}=v(x_s,s). \tag{1} \]

Let \(F_{t\to1}(x)\) denote the flow map obtained by integrating Eq. (1) from time \(t\) to time \(1\). For a small perturbation \(\delta x_t\),

\[ \delta x_1 \approx \Phi(1,t)\,\delta x_t, \tag{2} \]

where \(\Phi(1,t)\) is the state-transition operator of the reference marginal flow.

For a query state \(x_t\), define

\[ w(x_t,t) = \frac{1}{d}\operatorname{tr}\!\left(\Phi(1,t)^\top\Phi(1,t)\right) = \frac{1}{d}\|\Phi(1,t)\|_F^2, \tag{3} \]

where \(d=4\times8\times8=256\) is the dimensionality of the provided down-sampled latent code.

The desired reference curve is

\[ \boxed{ w_{\mathrm{avg}}(t) = \mathbb E_{x_t\sim p_t} \left[w(x_t,t)\right]. } \tag{4} \]
Terminology. Call this a reference \(w_{\mathrm{avg}}\), not unconditional ground truth. It is exact only relative to the selected GMM target model, the induced marginal flow, the numerical ODE solve, and the infinitesimal-perturbation limit.

2. Shared-\(\sigma\) GMM target latent distribution

The target distribution is fixed to

\[ \boxed{ p_1(y) = \frac{1}{N} \sum_{i=1}^{N} \mathcal N\!\left(y;\mu_i,\sigma^2I\right). } \tag{5} \]

Here:

  • \(N\) is the number of target latent samples / GMM components.
  • \(\mu_i\) is the center of component \(i\), taken from the pre-encoded target latents.
  • \(\sigma\) is one scalar standard deviation shared by all GMM components.
  • All components have equal weight \(1/N\). There is no configurable component-wise mixture weight.
Data source. Load the already down-sampled ImageNet latent codes from:
/scratch/project/prj-02-visual-ai/hkzhang/ILSVRC/latents_8_mean_fp16/train

Each latent has shape 4 × 8 × 8, so the working latent dimensionality is \(d=256\). Use these latent vectors directly as the GMM component centers \(\mu_i\). No additional pooling or spatial downsampling should be performed by this project.

3. Compute the reference marginal velocity

The standard independent conditional interpolation is used only to derive and sample the marginal distribution:

\[ x_t=(1-t)x_0+t y, \qquad x_0\sim\mathcal N(0,I), \qquad y\sim p_1. \tag{6} \]
Eq. (6) is the conditional coupling used to construct \(p_t\). It is not the trajectory followed by the marginal ODE.

Conditioned on GMM component \(i\),

\[ y\mid i\sim\mathcal N(\mu_i,\sigma^2I). \tag{7} \]

Therefore the time-\(t\) component marginal is

\[ x_t\mid i \sim \mathcal N\!\left( t\mu_i,\, s_t^2I \right), \tag{8} \]

where the shared time-dependent component variance is

\[ \boxed{ s_t^2=(1-t)^2+t^2\sigma^2. } \tag{9} \]

At a query point \((x,t)\), the posterior responsibility of component \(i\) is

\[ \boxed{ r_i(x,t) = \frac{ \mathcal N(x;t\mu_i,s_t^2I) }{ \sum_{j=1}^{N} \mathcal N(x;t\mu_j,s_t^2I) }. } \tag{10} \]

Because all components have equal prior weight \(1/N\), that common factor cancels from numerator and denominator.

3.1 Component-wise marginal velocity

For component \(i\), the conditional velocity of the linear interpolation is

\[ u=y-x_0. \]

Given that the query point satisfies \(x_t=x\), the required component velocity is the conditional expectation

\[ \boxed{ v_i(x,t) = \mathbb E[y-x_0\mid x_t=x,\ i]. } \tag{11} \]

Since \(x_0\) and \(y\mid i\) are Gaussian and \(x_t=(1-t)x_0+ty\) is linear in them, the pair \((y-x_0,x_t)\) is jointly Gaussian. The Gaussian conditional-mean identity gives

\[ \mathbb E[A\mid B=b] = \mathbb E[A] + \operatorname{Cov}(A,B) \operatorname{Var}(B)^{-1} \left(b-\mathbb E[B]\right). \tag{12} \]

For

\[ A=y-x_0, \qquad B=x_t, \]

the required moments are

\[ \mathbb E[A]=\mu_i, \qquad \mathbb E[B]=t\mu_i, \tag{13} \] \[ \operatorname{Var}(B) = s_t^2I, \tag{14} \] \[ \operatorname{Cov}(A,B) = \left[t\sigma^2-(1-t)\right]I. \tag{15} \]

Substituting Eqs. (13)-(15) into Eq. (12) yields

\[ \boxed{ v_i(x,t) = \mu_i + \frac{ t\sigma^2-(1-t) }{ (1-t)^2+t^2\sigma^2 } \left(x-t\mu_i\right). } \tag{16} \]
Interpretation of Eq. (16). The first term \(\mu_i\) is the mean conditional velocity for component \(i\). The second term corrects that mean according to where the query \(x\) lies relative to the component's time-\(t\) center \(t\mu_i\). The scalar coefficient is determined by the correlation between the instantaneous velocity \(y-x_0\) and the intermediate state \(x_t\). Before the minimum-scale point it is negative (component contraction); after that point it is positive (component expansion).

3.2 Reference marginal velocity

The full marginal velocity is the responsibility-weighted conditional expectation over GMM components:

\[ \boxed{ v(x,t) = \sum_{i=1}^{N} r_i(x,t)\,v_i(x,t). } \tag{17} \]

Eq. (17) is the velocity used for every forward ODE evaluation.

4. Sample query states \(x_t\sim p_t\)

For each query:

\[ i\sim\mathrm{Uniform}\{1,\ldots,N\}, \qquad y=\mu_i+\sigma\epsilon_y, \qquad \epsilon_y\sim\mathcal N(0,I), \tag{20} \] \[ x_0\sim\mathcal N(0,I), \qquad \boxed{ x_t=(1-t)x_0+t y. } \tag{21} \]

Eq. (21) is used only to draw a state from the correct marginal \(p_t\). Once \(x_t\) is sampled, propagate it to the endpoint using the marginal ODE in Eq. (1) with velocity Eq. (17).

5. Forward perturbation estimator

For each query \(x_t\), draw

\[ u\sim\mathcal N(0,I). \tag{22} \]

Propagate the unperturbed reference state

\[ x_1 = F_{t\to1}(x_t), \tag{23} \]

and the perturbed state

\[ x_1^{(+)} = F_{t\to1}(x_t+\varepsilon u). \tag{24} \]

For sufficiently small \(\varepsilon\),

\[ \frac{x_1^{(+)}-x_1}{\varepsilon} \approx \Phi(1,t)u. \tag{25} \]

Since \(\mathbb E[uu^\top]=I\),

\[ \mathbb E_u \left[ \left\| \frac{x_1^{(+)}-x_1}{\varepsilon} \right\|_2^2 \right] \rightarrow \|\Phi(1,t)\|_F^2. \tag{26} \]

With \(K\) probes,

\[ \boxed{ \widehat w(x_t,t) = \frac{1}{Kd\varepsilon^2} \sum_{k=1}^{K} \left\| F_{t\to1}(x_t+\varepsilon u_k) - F_{t\to1}(x_t) \right\|_2^2. } \tag{27} \]

With \(M\) marginal query states,

\[ \boxed{ \widehat w_{\mathrm{avg}}(t) = \frac1M \sum_{m=1}^{M} \widehat w(x_t^{(m)},t). } \tag{28} \]

Optional central difference

\[ \Phi(1,t)u \approx \frac{ F_{t\to1}(x_t+\varepsilon u) - F_{t\to1}(x_t-\varepsilon u) }{ 2\varepsilon }. \tag{29} \]

This roughly doubles ODE cost per probe but reduces finite-difference bias.

6.1 What each configuration control means

monte_carlo.num_probes (\(K_{\mathrm{probe}}\)) Number of random perturbation directions \(u\) used for each query state. This controls the accuracy of the directional estimate of \(\|\Phi(1,t)\|_F^2/d\). It is unrelated to a GMM cluster count.

responsibility_log_cutoff (\(\tau\)) Controls pruning of GMM components whose likelihood is negligible relative to the most likely component. Default \(\tau=30\). Section 9.2 explains the numerical bound.
ode.solver, rtol, atol Numerical integrator and error tolerances for the marginal ODE. These must be tight enough that ODE numerical error is much smaller than the perturbation-induced endpoint difference.
distributed.num_gpus Number of GPUs used for distributed evaluation. Production target: 8 GPUs.
output.output_dir Directory for resolved config, logs, intermediate per-timestep statistics, CSV/JSON values, and figures.

Inputs from config:

  component_sigma
  time grid T = {t_1,...,t_L}
  M = query states per t
  K_probe = perturbation directions per query
  epsilon rule: eps = alpha * s_t
  responsibility pruning cutoff tau
  ODE solver and tolerances
  distributed / GPU settings

Precompute:
  1. Discover all latent files/records under latent_root.
  2. Load all latent codes by default as GMM centers mu_i.
     Each latent is already 4 x 8 x 8; do not pool or downsample again.
  3. Show loading progress, elapsed time, throughput, and ETA during loading.
  4. Flatten each latent to d = 256 for GMM computation.
  5. Implement reference_velocity(x,t) using the shared-sigma GMM formulas.

For each t in T:
    per_state = []

    for each distributed query-state batch:
        # A. Draw x_t from the shared-sigma GMM-induced marginal.
        x_t = sample_gmm_marginal(t)

        # B. Unperturbed reference endpoint.
        x1 = solve_marginal_ode(x_t, t, 1)

        # C. Perturbation probes.
        for k in 1..K_probe:
            u = Normal(0, I)
            x1p = solve_marginal_ode(x_t + eps*u, t, 1)
            g = (x1p - x1) / eps
            w_query_probe = ||g||^2 / d

        w_query = mean_over_probes(w_query_probe)

    # D. Distributed reduction across 8 GPUs.
    w_avg[t] = global_mean(w_query)
    stderr[t] = global_standard_error(w_query)

Optional normalization:
    w_norm(t) = w_avg(t) / integral_0^1 w_avg(s) ds

7. Validation before the full experiment

7.1 Single isotropic Gaussian sanity check

Set

\[ p_1=\mathcal N(0,\sigma^2I). \tag{30} \]

Then

\[ c(t)^2=(1-t)^2+\sigma^2t^2, \tag{31} \]

and the exact squared amplification is

\[ \boxed{ w(t) = \frac{\sigma^2} {(1-t)^2+\sigma^2t^2}. } \tag{32} \]

The peak must occur at

\[ \boxed{ t_{\mathrm{peak}} = \frac{1}{1+\sigma^2}. } \tag{33} \]

The implementation must reproduce both the analytical curve and peak position before the ImageNet experiment.

7.2 Perturbation-size convergence and \(\varepsilon\) sweep

Because \(u\sim\mathcal N(0,I)\), \(\varepsilon\) is the RMS perturbation scale per coordinate. Define the typical marginal RMS scale

\[ s_t = \sqrt{ \mathbb E_{x_t\sim p_t} \left[ \frac{\|x_t\|_2^2}{d} \right] }. \tag{34} \]

Use

\[ \varepsilon=\alpha s_t. \tag{35} \]

For the initial test, sweep

\[ \boxed{ \alpha \in \{10^{-4},\,3\times10^{-4},\,10^{-3},\,3\times10^{-3},\,10^{-2},\,3\times10^{-2}\}. } \tag{36} \]
  • Large \(\alpha\): nonlinear finite-difference bias.
  • Very small \(\alpha\): floating-point cancellation and ODE solver error.
  • Select \(\alpha\) from a stable plateau where the resulting \(w_{\mathrm{avg}}\) curve changes minimally as \(\alpha\) varies.

7.3 Monte Carlo convergence

Increase \(M\) and \(K\) independently and measure how the estimated curve and sampling uncertainty change. In high dimension, increasing \(M\) may be more useful than using a large \(K\) for each query state.

8. Numerical and computational issues

8.1 Stable responsibility computation: log-space normalization

At fixed \(t\), all GMM components have equal prior weight and the same covariance \(s_t^2I\). Therefore, when computing responsibilities, all Gaussian normalization constants are common across components and cancel. It is sufficient to use the relative log score

\[ \ell_i(x,t) = -\frac{\|x-t\mu_i\|_2^2}{2s_t^2}. \]

A direct implementation of \(\exp(\ell_i)\) is unsafe in high dimension: squared distances can be large, making essentially every Gaussian density underflow to zero in floating point. The stable strategy is to subtract the largest log score before exponentiation:

\[ m=\max_i\ell_i, \qquad r_i = \frac{\exp(\ell_i-m)} {\sum_j\exp(\ell_j-m)}. \]

Now the largest exponential is exactly \(1\), and every other exponential lies in \((0,1]\). This removes the irrelevant absolute density scale and preserves the relative probabilities needed by the marginal velocity. 

score_i = - squared_distance(x, t * mu_i) / (2 * s_t_sq)

global_max = max(score_i over ALL N components)
shifted_i  = score_i - global_max

# pruning is applied only after global_max is known
keep = shifted_i >= -tau

denominator = sum(exp(shifted_i[keep]))
r_i = exp(shifted_i[keep]) / denominator
Chunked / distributed requirement. The maximum must be the maximum over all \(N\) components, not the maximum of an independently normalized chunk. If components are processed in chunks, first obtain the global maximum (or use an equivalent online log-sum-exp algorithm), then accumulate the globally shifted exponential sum and velocity numerator. If components are sharded over GPUs, use distributed reductions for the global maximum and global sums.

8.2 Prune numerically negligible components

After the global maximum log score \(m\) has been found, drop a component when

\[ \boxed{ \ell_i < m-\tau. } \tag{37} \]

For the default \(\tau=30\), every dropped component has unnormalized weight at most

\[ e^{-30}\approx9.36\times10^{-14} \]

times the maximum component weight. This is not only an underflow safeguard; it also avoids spending most of the computation on components whose contribution to the marginal velocity is negligible.

There is a simple worst-case bound. If the loader discovers \(N\) total components, the total posterior mass that can be discarded is bounded by

\[ \text{dropped mass} \le N e^{-\tau}, \]

because the normalizing denominator is at least the maximum component weight. Since production uses all available latents, \(N\) is determined at runtime. The program should report the corresponding bound \(N e^{-\tau}\) for the configured cutoff.

More generally, to target a worst-case omitted mass below \(\delta\), choose

\[ \tau \ge \log\!\left(\frac{N}{\delta}\right). \]
Important. Pruning is applied during responsibility evaluation; it does not change how query states are sampled from the GMM. Always renormalize the retained responsibilities. Keep \(\tau\) configurable and verify on a smaller run that increasing \(\tau\) does not change the resulting \(w_{\mathrm{avg}}(t)\) curve appreciably.

8.3 Complexity

\[ O\!\left( L\,M\,(K+1)\,S\,N\,d \right), \tag{39} \]

where \(L\) is the number of queried times, \(S\) is the number of marginal-velocity evaluations made by the ODE solver, \(N\) is the number of GMM components, and \(d\) is pooled latent dimension.

The dominant cost is evaluating component likelihoods/responsibilities at every marginal-velocity query.

8.4 Safe acceleration

  • Chunk over GMM components: exact if all chunks participate in the global log-sum-exp and weighted numerator.
  • Batch query and perturbation states: exact.
  • Responsibility cutoff: approximate; configurable and validated.
  • Cache time-dependent shared scalars: \(s_t^2\), its inverse, and Gaussian normalization terms.

8.5 Finite-difference ODE consistency

The purpose of this section is to make sure the measured endpoint difference is caused by the initial perturbation \(\varepsilon u\), rather than by unrelated numerical error from the two ODE solves.

The ideal estimator uses

\[ \frac{ F_{t\to1}(x_t+\varepsilon u) - F_{t\to1}(x_t) }{\varepsilon}. \]

Suppose the numerical ODE solver returns \(F+\eta\), where \(\eta\) is its endpoint integration error. Then the actual finite-difference estimate contains

\[ \frac{\eta_{+}-\eta_{0}}{\varepsilon}. \]

Because this error is divided by \(\varepsilon\), it can become important precisely when \(\varepsilon\) is made very small. This is why the \(\varepsilon\)-convergence test and the ODE-tolerance test must be considered together.

Implementation requirements:

  • use the same reference marginal velocity code for both trajectories;
  • use the same ODE solver and identical tolerances;
  • prefer a deterministic fixed-step/common time grid for the finite-difference experiment when practical; if an adaptive solver is used, require sufficiently tight tolerances;
  • repeat a subset of the experiment with tighter ODE tolerances and verify that \(w_{\mathrm{avg}}(t)\) is stable;
  • choose \(\varepsilon\) only from a regime where the perturbation signal is clearly larger than the solver-induced endpoint noise.
FP32 recommendation. Keep GMM distances, log scores, responsibilities, states, velocities, and ODE integration in FP32. Integrate the unperturbed state and all perturbations together in one batched ODE solve whenever practical so they share the same solver time grid/step decisions. Use FP64 only for inexpensive final scalar reductions (means, variances, confidence intervals) if desired.
Intention of Sec. 8.5. It is not an additional modeling assumption. It is a numerical-control condition for the finite-difference measurement of \(\Phi(1,t)u\).

9. Required outputs and figures

  1. Raw curve. Save numerical values of \(\widehat w_{\mathrm{avg}}(t)\) to CSV/JSON and plot \(t\) versus raw \(\widehat w_{\mathrm{avg}}(t)\).
  2. Normalized curve. Compute \[ \widetilde w(t) = \frac{ w_{\mathrm{avg}}(t) }{ \int_0^1 w_{\mathrm{avg}}(s)\,ds } \tag{42} \] and plot the normalized curve.
  3. Sampling uncertainty and confidence band. At each \(t\), retain the per-query estimates \(\widehat w_m(t)\), compute \[ \mathrm{SE}(t) = \frac{\mathrm{Std}_m[\widehat w_m(t)]}{\sqrt{M}}, \tag{43} \] and plot the mean curve with a shaded mean \(\pm1.96\,\mathrm{SE}(t)\) band. This measures Monte Carlo uncertainty across sampled marginal query states.
  4. Peak location. Report \(t_{\mathrm{peak}}\) numerically and mark it on the raw and normalized plots.
  5. Single-Gaussian sanity-check figure. Plot the numerical estimate against the analytical Eq. (32), and report curve error plus peak-location error.
  6. Convergence figures. Plot the \(\varepsilon\)-sweep and selected \(M/K\) convergence tests to demonstrate numerical stability.

Save all figures as PNG and, when practical, PDF. Save the underlying numerical data used for every plot.

Critical rule for the code agent.
Conditional interpolation is used only to derive and sample \(p_t\). It must not be used to propagate the unperturbed or perturbed query to the endpoint. Both trajectories must be integrated through the reference marginal velocity field \(v(x,t)\) in Eq. (17).
